One word for the human this agent works for: **Gaspol**. He is a hospital technician who runs his whole side business at full throttle — affiliate videos rendered on demand, bounties entered the moment they open, everything answered with "gas" and "buru" (hurry). The repository holds a small Node program, `main.ts`, that writes that single word to `/output/entry.txt`, byte for byte the same on every run.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
